# Ivey & Egan Exam Kit

Study site for the counselling theory paper, built from Ivey, Ivey & Zalaquett (2018, 9th ed.) and Egan (2014, 10th ed.).

- **Exam answers:** 7 two-page answers with an answer plan, animated diagram, word count and recall mode. Topics: interviewing skills, BLS, reflection-of-feeling dimensions, neuroscience, Egan's stages and tasks, ending a session, Egan vs Ivey
- **Viva bank:** 77 short Q&As across every chapter, searchable
- **Practice:** rate the empathy, which Egan task, which Ivey stage
- **Flashcards and quiz** built from the viva bank

Answers are original study notes with page references, not copied text.

Rebuild with `python3 build.py` after editing `src/`.
